# 🧮 Считаем с палочками Кюизенера

Интерактивная развивающая игра для детей старшего дошкольного возраста (5–7 лет), направленная на формирование элементарных математических представлений. 

👉 **[Открыть и играть в браузере](https://irina-krainskaya.github.io/igra5/)**

---

### 🎯 О чём эта игра?
С помощью классических цветных счётных палочек Кюизенера ребёнок в наглядной и увлекательной форме учится решать примеры на сложение в пределах первого десятка.

### ✨ Особенности тренажёра:
* **Наглядная опора:** числа в примерах представлены цветными палочками разной длины (от белой единицы до оранжевой десятки), что помогает соотносить цвет и размер с числовым значением.
* **Удобное управление:** для ответа достаточно выбрать нужное число на верхней панели (от 1 до 10) и перенести его на место знака вопроса.
* **Подсказки и самоконтроль:** 
  * Счётчик вверху экрана отслеживает прогресс (20 примеров за сессию).
  * Кнопка **«Подсказка (1-10)»** помогает свериться с числовым рядом при затруднениях.
  * Кнопка **«Новые примеры»** генерирует свежие задания для закрепления материала.
